# mtncloud_http_task

A HTTP task (console: Library > Automation > Tasks). Calls an HTTP endpoint; the response is the task's result.

## Example Usage

```terraform
resource "mtncloud_http_task" "notify" {
  name        = "notify-deploy"
  url         = "https://hooks.example.com/deploy"
  method      = "POST"
  body        = jsonencode({ instance = "<%=instance.name%>" })
  headers     = { "Content-Type" = "application/json" }
  credential  = "deploy-hook"
  result_type = "json"
}
```

## Schema

### Required

- `name` (String) Task name.
- `url` (String) The URL to call, for example `https://api.example.com/hooks/deploy`.

### Optional

- `allow_custom_config` (Boolean) Let whoever runs the task pass custom configuration. Defaults to false.
- `body` (String) Request body.
- `code` (String) Task code, a short unique reference.
- `credential` (String) A stored credential to authenticate with, by name (`mtncloud_credentials` lists them), instead of `user` and `password`.
- `headers` (Map of String) Request headers, for example `{ "Content-Type" = "application/json" }`.
- `ignore_ssl` (Boolean) Don't verify the endpoint's TLS certificate. Defaults to false.
- `labels` (Set of String) Labels.
- `method` (String) HTTP method, for example `GET` or `POST`. The platform's default is `GET`.
- `password` (String, Sensitive) Password for basic authentication. Stored in state (sensitive); not read back, so a change made in the console isn't seen.
- `result_type` (String) How to read the task's output for later tasks: `value`, `keyValue` or `json`. Leave it out to ignore it.
- `retry_count` (Number) How many times to retry when `retryable` is true. Defaults to 5.
- `retry_delay_seconds` (Number) Seconds between retries. Defaults to 10.
- `retryable` (Boolean) Retry the task when it fails. Defaults to false.
- `user` (String) User for basic authentication. Leave it out when `credential` is set.
- `visibility` (String) `private` (your tenant only, the default) or `public`.

### Read-Only

- `id` (String) Task ID.
