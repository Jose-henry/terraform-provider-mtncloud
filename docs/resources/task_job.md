# mtncloud_task_job

Provides an MTN Cloud task job resource: runs a task on a schedule or once, against instances or servers.

## Example Usage

**Manual**

```terraform
data "mtncloud_task" "example_task" {
  name = "Deploy app"
}

# Runs on every VM labelled "demo" when started by hand.
resource "mtncloud_task_job" "manual" {
  name           = "Deploy app (manual)"
  enabled        = true
  labels         = ["demo"]
  task_id        = data.mtncloud_task.example_task.id
  schedule_mode  = "manual"
  context_type   = "instance-label"
  instance_label = "demo"
}
```

**Date and Time**

```terraform
data "mtncloud_task" "example_task" {
  name = "Deploy app"
}

data "mtncloud_instance" "web" {
  name = "web-1"
}

resource "mtncloud_task_job" "date_and_time" {
  name                    = "Deploy app (once)"
  enabled                 = true
  labels                  = ["demo"]
  task_id                 = data.mtncloud_task.example_task.id
  schedule_mode           = "date_and_time"
  scheduled_date_and_time = "2027-01-30T06:00:00Z"
  context_type            = "instance"
  instance_ids            = [data.mtncloud_instance.web.id]
}
```

**Execution Schedule**

```terraform
data "mtncloud_task" "example_task" {
  name = "Deploy app"
}

data "mtncloud_instance" "web" {
  name = "web-1"
}

# The schedule must be enabled: MTN Cloud refuses a job on a disabled one ("Schedule not found").
data "mtncloud_execute_schedule" "example_schedule" {
  name = "Run Daily at 9 AM"
}

resource "mtncloud_task_job" "schedule" {
  name                  = "Deploy app (daily)"
  enabled               = true
  labels                = ["demo"]
  task_id               = data.mtncloud_task.example_task.id
  schedule_mode         = "scheduled"
  execution_schedule_id = data.mtncloud_execute_schedule.example_schedule.id
  context_type          = "instance"
  instance_ids          = [data.mtncloud_instance.web.id]
}
```


## Notes

- `context_type = "appliance"` (run on the platform itself) isn't open to tenant logins: MTN Cloud answers
  "Target Type not found". Target VMs by `instance`, `server`, `instance-label` or `server-label`.
- A `scheduled` job needs an **enabled** `mtncloud_execute_schedule`; on a disabled one MTN Cloud answers
  "Schedule not found with id N".

## Schema

### Required

- `context_type` (String) The context that the job should run as (appliance, server, instance, instance-label, server-label)
- `name` (String) The name of the task job
- `schedule_mode` (String) The job scheduling type (manual, date_and_time, scheduled)
- `task_id` (Number) The id of the task associated with the job

### Optional

- `custom_config` (String) The task custom configuration
- `enabled` (Boolean) Whether the task job is enabled
- `execution_schedule_id` (Number) The id of the execution schedule associated with the job
- `instance_ids` (List of Number) A list of instance ids to associate with the job
- `instance_label` (String) The instance label used for dynamic automation targeting
- `labels` (Set of String) The organization labels associated with the task job (Only supported on MTN Cloud 5.5.3 or higher)
- `scheduled_date_and_time` (String) The date and time the job will be executed if schedule mode date_and_time is used
- `server_ids` (List of Number) A list of server ids to associate with the job
- `server_label` (String) The server label used for dynamic automation targeting

### Read-Only

- `id` (String) The ID of the task job
