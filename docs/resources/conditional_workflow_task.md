# mtncloud_conditional_workflow_task

A Conditional Workflow task (console: Library > Automation > Tasks). Runs one operational workflow or another, depending on a JavaScript condition.

## Example Usage

```terraform
resource "mtncloud_conditional_workflow_task" "by_env" {
  name          = "patch-by-environment"
  condition     = "return instance.instanceContext == 'production'"
  if_workflow   = "patch-with-approval"
  else_workflow = "patch-now"
}
```

## Schema

### Required

- `if_workflow` (String) The operational workflow run when the condition is true, by name.
- `name` (String) Task name.

### Optional

- `allow_custom_config` (Boolean) Let whoever runs the task pass custom configuration. Defaults to false.
- `code` (String) Task code, a short unique reference.
- `condition` (String) JavaScript that returns true or false. True runs `if_workflow`, false `else_workflow`.
- `else_workflow` (String) The operational workflow run when the condition is false, by name. Leave it out to do nothing.
- `labels` (Set of String) Labels.
- `retry_count` (Number) How many times to retry when `retryable` is true. Defaults to 5.
- `retry_delay_seconds` (Number) Seconds between retries. Defaults to 10.
- `retryable` (Boolean) Retry the task when it fails. Defaults to false.
- `visibility` (String) `private` (your tenant only, the default) or `public`.

### Read-Only

- `id` (String) Task ID.
