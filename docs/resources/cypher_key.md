# mtncloud_cypher_key

A Base64 AES key that MTN Cloud generates and keeps in Cypher, its secret store, under `key/`. Workflows read it with `<%=cypher.read('key/<name>')%>`. Destroying it deletes the key.

## Example Usage

```terraform
resource "mtncloud_cypher_key" "app" {
  name = "app-encryption"
  bits = 256
}
```

## Schema

### Required

- `name` (String) Key name, without the `key/` mount, for example `db-admin`. Changing it makes a new Base64 AES key.

### Optional

- `bits` (Number) Key length in bits: 128, 192 or 256. Defaults to 256. Changing it makes a new Base64 AES key.
- `ttl` (String) Lease: how long the Base64 AES key lives before MTN Cloud deletes it, in seconds or as `15m`, `8h`, `7d`. Leave it out, or `0`, to keep it for good. Changing it makes a new Base64 AES key.

### Read-Only

- `id` (String) The Cypher key as stored, for example `key/db-admin`.
- `value` (String, Sensitive) The generated Base64 AES key. It is stored in the Terraform state (marked sensitive): protect the state.

## Import

Import is supported using the following syntax:

```shell
# Imported by its Cypher key, as mtncloud_cyphers lists it.
terraform import mtncloud_cypher_key.app key/256/app-encryption
```
