# mtncloud_powerscale_storage_collection_task

A PowerScale Storage Collection task (console: Library > Automation > Tasks). Collects PowerScale storage usage for billing.

## Example Usage

```terraform
resource "mtncloud_powerscale_storage_collection_task" "usage" {
  name    = "powerscale-usage"
  dry_run = true
}
```
