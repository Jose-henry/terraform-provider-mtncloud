# mtncloud_cypher_tfvars

Provides an MTN Cloud Cypher tfvars secret resource: Terraform variable values stored in Cypher under `tfvars/`, for Terraform blueprints.

## Example Usage

```terraform
resource "mtncloud_cypher_tfvars" "tf_example_cypher_tfvars" {
  key   = "securetfvars"
  value = <<EOT
account=12345
password=supersecure
EOT
  ttl   = 86400
}
```

## Schema

### Required

- `key` (String) The path of the cypher tfvars secret, excluding the secret prefix
- `value` (String, Sensitive) The value of the cypher tfvars secret

### Optional

- `ttl` (Number) The time to live of the cypher tfvars secret

### Read-Only

- `id` (String) The ID of the cypher tfvars secret

## Import

Import is supported using the following syntax:

```shell
# By the entry's ID (shown in the console), or by its key, with or without the mount.
terraform import mtncloud_cypher_tfvars.tf_example_cypher_tfvars 1
terraform import mtncloud_cypher_tfvars.tf_example_cypher_tfvars tfvars/app/db
# A key made only of digits needs its mount, or it is read as an ID.
terraform import mtncloud_cypher_tfvars.tf_example_cypher_tfvars tfvars/2024
```
