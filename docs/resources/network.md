# mtncloud_network

An MTN Network: a private network in one project, created in OpenStack with one subnet of the same range. Connect it to other networks or the internet with an MTN Router. Creating it waits until OpenStack reports it ready, usually within seconds.

## Example Usage

```terraform
# An MTN Network in a project. DNS defaults to MTN's resolvers; DHCP and
# static-address override are on by default.
resource "mtncloud_network" "app" {
  name        = "app-net"
  description = "Application tier"
  project     = "web-prod"
  cidr        = "10.20.1.0/24"
  gateway     = "10.20.1.1"
}

# With IPv6 as well, and your own DNS servers.
resource "mtncloud_network" "dual_stack" {
  name          = "edge-net"
  project       = "web-prod"
  cidr          = "10.20.2.0/24"
  gateway       = "10.20.2.1"
  dns_primary   = "102.89.90.112"
  dns_secondary = "120.91.123.54"

  ipv6 = {
    cidr    = "2001:db8:2::/64"
    gateway = "2001:db8:2::1"
  }
}

# The subnet an MTN Router attaches to.
output "app_subnet_id" {
  value = mtncloud_network.app.subnet_id
}
```

## Schema

### Required

- `cidr` (String) IPv4 address range, for example `10.0.1.0/24`. It can't change: a new range replaces the network.
- `gateway` (String) Gateway address inside `cidr`, usually its first address (`10.0.1.1` for `10.0.1.0/24`).
- `name` (String) Name of the network.
- `project` (String) Project the network is created in, by name (for example `web-prod`; the full name with the tenant suffix also works). Changing it to another project replaces the network.

### Optional

- `allow_ip_override` (Boolean) Let instances choose a static address on this network instead of DHCP. Defaults to `true`.
- `description` (String) Description of the network.
- `dhcp_enabled` (Boolean) Hand out addresses with DHCP. Defaults to `true`.
- `dns_primary` (String) Primary DNS server. Defaults to MTN's resolver `102.88.134.41`. MTN's resolvers are `102.88.134.41`, `102.90.109.125`, `102.89.90.112` and `120.91.123.54`.
- `dns_secondary` (String) Secondary DNS server. Defaults to MTN's resolver `102.90.109.125`. Both DNS servers are always set: a network imported without one gets MTN's resolver on the next apply.
- `ipv6` (Attributes) IPv6 settings. Leave it out to keep IPv6 off (the default). Turning IPv6 on or off, or changing its `cidr`, replaces the network. (see [below for nested schema](#nestedatt--ipv6))
- `timeouts` (Block, Optional) (see [below for nested schema](#nestedblock--timeouts))

### Read-Only

- `external_id` (String) OpenStack (Neutron) network ID.
- `id` (String) Network ID.
- `subnet_id` (String) ID of the subnet OpenStack created with the network. An MTN Router attaches to it.

## Import

Import is supported using the following syntax:

```shell
terraform import mtncloud_network.app 9301
```

## Notes

- **Waits until ready.** A new network is "provisioning" for a few seconds; create waits for MTN Cloud
  to report it ready (default timeout 10 minutes, see `timeouts`), so routers and instances in the
  same apply only use it once it works. A network that fails is reported and replaced by the next apply.
- **Can't change in place:** `cidr`, `project` (another project), and IPv6 turned on or off or given
  a new range. Each replaces the network, which fails while instances or a router use it.
- **Rejected designs.** MTN Cloud refuses a network whose range clashes with another one in the
  project, or whose settings don't fit together. The error shows MTN Cloud's own message and nothing
  is saved in state.
- **Deleting** a network that instances, a router or a load balancer still use fails ("ports still in
  use"). Remove them first; Terraform does this itself when they reference the network in the same
  configuration.
- **Import** stores the project's short name (`web-prod`). Write it that way in the configuration:
  with the full name (`web-prod-<tenant>`) the first plan shows an in-place update that changes
  nothing.
- **Names are unique per project.** Creating a network whose name is already used in the project
  fails and gives its ID, so you can import it instead.
