# mtncloud_app

A blank app: a named set of existing instances, shown together in the console. Add instances with `mtncloud_app_instance`. **Destroy deletes the app and leaves its instances running.** For an app a catalog order made, use `mtncloud_app_settings`.

## Example Usage

```terraform
resource "mtncloud_app" "shop" {
  name        = "shop"
  description = "Shop front and its workers"
  labels      = ["shop"]
  environment = "Production"
}

resource "mtncloud_instance" "web" {
  name             = "shop-web-1"
  project          = "web-prod"
  image            = "MTN Ubuntu Server 24.04.3LTS"
  plan             = "G2S4"
  root_volume_size = 40
  networks         = ["app-net"]
}

# The instance joins the app's Web tier. Destroying the app leaves the instance running.
resource "mtncloud_app_instance" "web" {
  app_id      = mtncloud_app.shop.id
  instance_id = mtncloud_instance.web.id
  tier        = "Web"
}
```

## Notes

- **Destroy keeps the instances.** The app is deleted; its instances keep running, and are deleted
  through whatever made them.
- **Members** join with `mtncloud_app_instance`, one per instance.
- **Names are unique** in your tenant: a name already in use is refused at apply, with the import command.
- **Catalog orders' apps** belong to their order: manage their settings with `mtncloud_app_settings`.

## Schema

### Required

- `name` (String) Name, unique in your tenant. Changed in place.

### Optional

- `description` (String) Description, changed in place.
- `environment` (String) Environment by name or code, for example `Production`. Changed in place.
- `group` (String) Group, by name, for example `MTNNG_CLOUD_AZ_1`. Defaults to the provider's `group`. Changing it replaces the app.
- `labels` (Set of String) Labels, changed in place; `[]` clears them.

### Read-Only

- `id` (String) The app's ID.
- `instance_ids` (Set of String) IDs of the instances in the app.
- `status` (String) The app's status, for example `running`.

## Import

Import is supported using the following syntax:

```shell
# By the app's ID.
terraform import mtncloud_app.shop 9901
```
