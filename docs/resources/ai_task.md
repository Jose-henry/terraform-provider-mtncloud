# mtncloud_ai_task

A AI Task task (console: Library > Automation > Tasks). Asks one of your AI agents a prompt; the answer is the task's result.

## Example Usage

```terraform
resource "mtncloud_ai_task" "summary" {
  name        = "summarise-instance"
  ai_agent    = "ops-assistant"
  prompt      = "Summarise the health of <%=instance.name%> in two sentences."
  result_type = "value"
}
```

## Schema

### Required

- `ai_agent` (String) The AI agent to ask, by name.
- `name` (String) Task name.

### Optional

- `allow_custom_config` (Boolean) Let whoever runs the task pass custom configuration. Defaults to false.
- `code` (String) Task code, a short unique reference.
- `labels` (Set of String) Labels.
- `prompt` (String) The prompt. Workflow variables such as `<%=instance.name%>` work.
- `result_type` (String) How to read the task's output for later tasks: `value`, `keyValue` or `json`. Leave it out to ignore it.
- `retry_count` (Number) How many times to retry when `retryable` is true. Defaults to 5.
- `retry_delay_seconds` (Number) Seconds between retries. Defaults to 10.
- `retryable` (Boolean) Retry the task when it fails. Defaults to false.
- `visibility` (String) `private` (your tenant only, the default) or `public`.

### Read-Only

- `id` (String) Task ID.

## Import

Import is supported using the following syntax:

```shell
# A task is imported by its ID; mtncloud_tasks lists them.
terraform import mtncloud_ai_task.summary 1234
```
