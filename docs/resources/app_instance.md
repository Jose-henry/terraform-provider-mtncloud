# mtncloud_app_instance

An existing instance in an app's tier. Create adds it to the app; **destroy takes it out of the app and leaves it running** (delete the instance through whatever owns it). Taking a node out of a managed service's app can break the service. Destroying the order that made the app takes instances added this way out of it first and leaves them running.

## Example Usage

```terraform
resource "mtncloud_self_managed_kubernetes" "k8s" {
  name                    = "apps-k8s"
  project                 = "web-prod"
  master_plan             = "G2S4"
  master_root_volume_size = 50
  master_networks         = ["app-net"]
  master_security_groups  = ["web"]
  worker_plan             = "G4S16"
  worker_root_volume_size = 100
  worker_networks         = ["app-net"]
  worker_security_groups  = ["web"]
  worker_count            = 3
}

data "mtncloud_network" "app" {
  name    = "app-net"
  project = "web-prod"
}

# A monitoring VM this configuration made, shown in the cluster's app.
resource "mtncloud_instance" "monitor" {
  name             = "k8s-monitor"
  project          = "web-prod"
  image            = "MTN Ubuntu Server 24.04.3LTS"
  plan             = "G2S4"
  root_volume_size = 40
  networks         = [data.mtncloud_network.app.id]
}

resource "mtncloud_app_instance" "monitor" {
  app_id      = mtncloud_self_managed_kubernetes.k8s.app_id
  instance_id = mtncloud_instance.monitor.id
  tier        = "Monitoring"
}
```

## Notes

- **Destroy keeps the instance.** It only takes the instance out of the app; the instance keeps running.
- **Managed services.** Taking a node out of a managed service's app can break the service: only add and
  remove instances you made yourself.
- **Order destroy.** Destroying the order that made the app takes instances added this way out of the app
  first and leaves them running.
- **Moving tiers.** Changing `tier` takes the instance out and puts it back in the new tier.

## Schema

### Required

- `app_id` (String) ID of the app, for example an order's `app_id`.
- `instance_id` (String) ID of the instance, for example `mtncloud_instance.worker.id`.
- `tier` (String) Tier to put it in, for example `App` or `Worker`. A tier the app doesn't have yet is created. Changing it moves the instance (out, then in).

### Read-Only

- `id` (String) `<app_id>/<instance_id>`.

## Import

Import is supported using the following syntax:

```shell
# By <app_id>/<instance_id>. Import adopts the membership; the app and the instance are left alone.
terraform import mtncloud_app_instance.monitor 9901/9750
```
