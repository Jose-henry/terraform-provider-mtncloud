# mtncloud_dynamic_wallet_collection_task

A Dynamic Wallet Collection task (console: Library > Automation > Tasks). Runs MTN's dynamic wallet collection. It has no options of its own.

## Example Usage

```terraform
resource "mtncloud_dynamic_wallet_collection_task" "wallet" {
  name           = "wallet-collection"
  execute_target = "local"
}
```
