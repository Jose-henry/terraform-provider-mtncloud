# mtncloud_managed_kubernetes (deprecated)

Renamed to [`mtncloud_self_managed_kubernetes`](self_managed_kubernetes.md): the cluster is
self-managed, so the old name was misleading. This name still works, with a deprecation warning, and
will be removed in a later release.

Move to the new name without replacing anything (Terraform 1.8 or newer): rename the resource, then
add a `moved` block and apply.

```terraform
moved {
  from = mtncloud_managed_kubernetes.k8s
  to   = mtncloud_self_managed_kubernetes.k8s
}
```

On Terraform older than 1.8, take it out of state and import it under the new name, by its order ID
(Catalog > Inventory). The first apply after the import records the inputs and orders nothing:

```shell
terraform state rm mtncloud_managed_kubernetes.k8s
terraform import mtncloud_self_managed_kubernetes.k8s <order id>
```
