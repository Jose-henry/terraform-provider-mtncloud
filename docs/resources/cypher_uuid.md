# mtncloud_cypher_uuid

A UUID that MTN Cloud generates and keeps in Cypher, its secret store, under `uuid/`. Workflows read it with `<%=cypher.read('uuid/<name>')%>`. Destroying it deletes the key.

## Example Usage

```terraform
resource "mtncloud_cypher_uuid" "mac" {
  name = "build-mac-1"
  ttl  = "7d"
}
```

## Schema

### Required

- `name` (String) Key name, without the `uuid/` mount, for example `db-admin`. Changing it makes a new UUID.

### Optional

- `ttl` (String) Lease: how long the UUID lives before MTN Cloud deletes it, in seconds or as `15m`, `8h`, `7d`. Leave it out, or `0`, to keep it for good. Changing it makes a new UUID.

### Read-Only

- `id` (String) The Cypher key as stored, for example `uuid/db-admin`.
- `value` (String, Sensitive) The generated UUID. It is stored in the Terraform state (marked sensitive): protect the state.

## Import

Import is supported using the following syntax:

```shell
# Imported by its Cypher key, as mtncloud_cyphers lists it.
```
