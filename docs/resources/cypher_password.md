# mtncloud_cypher_password

A password that MTN Cloud generates and keeps in Cypher, its secret store, under `password/`. Workflows read it with `<%=cypher.read('password/<name>')%>`. Destroying it deletes the key.

## Example Usage

```terraform
resource "mtncloud_cypher_password" "db_admin" {
  name   = "db-admin"
  length = 24
}

# Pass it to something that needs it, for example a catalog order's admin password.
output "db_admin_password" {
  value     = mtncloud_cypher_password.db_admin.value
  sensitive = true
}
```

## Schema

### Required

- `name` (String) Key name, without the `password/` mount, for example `db-admin`. Changing it makes a new password.

### Optional

- `length` (Number) Number of characters, with symbols, digits, upper and lower case letters. Defaults to 15. Changing it makes a new password.
- `ttl` (String) Lease: how long the password lives before MTN Cloud deletes it, in seconds or as `15m`, `8h`, `7d`. Leave it out, or `0`, to keep it for good. Changing it makes a new password.

### Read-Only

- `id` (String) The Cypher key as stored, for example `password/db-admin`.
- `value` (String, Sensitive) The generated password. It is stored in the Terraform state (marked sensitive): protect the state.

## Import

Import is supported using the following syntax:

```shell
# Imported by its Cypher key, as mtncloud_cyphers lists it.
terraform import mtncloud_cypher_password.db_admin password/24/db-admin
```
