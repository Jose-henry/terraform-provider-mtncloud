# mtncloud_monitoring_setting

Provides a MTN Cloud monitoring setting resource.

## Example Usage

```terraform
resource "mtncloud_monitoring_setting" "tf_example_guidance_setting" {
  mtncloud_auto_create_checks         = true
  mtncloud_availability_time_frame    = 30
  mtncloud_availability_precision     = 4
  mtncloud_default_check_interval     = 120
  servicenow_monitoring_enabled       = true
  servicenow_integration_id           = 1
  servicenow_new_incident_action      = "create"
  servicenow_close_incident_action    = "activity"
  servicenow_severity_info_impact     = "high"
  servicenow_severity_warning_impact  = "high"
  servicenow_severity_critical_impact = "low"
  new_relic_monitoring_enabled        = true
  new_relic_license_key               = "ABC123"
}
```

## Schema

### Optional

- `mtncloud_auto_create_checks` (Boolean) When enabled a Monitoring Check will automatically be create for Instances and Apps
- `mtncloud_availability_precision` (Number) The number of decimal places availability should be displayed in, can be anywhere between 0 and 5
- `mtncloud_availability_time_frame` (Number) The number of days availability should be calculated for
- `mtncloud_default_check_interval` (Number) The default interval in minutes to use when creating new checks (1, 2, 3, 4, 5, 10, 15, 20, 25, 30, 45, 60, 120, 180)
- `new_relic_license_key` (String) The New Relic license key
- `new_relic_monitoring_enabled` (Boolean) Whether the New Relic monitoring integration is enabled
- `servicenow_close_incident_action` (String) The Service Now action to take when a MTN Cloud incident is closed (activity, close, none)
- `servicenow_integration_id` (Number) The id of the ServiceNow monitoring integration
- `servicenow_monitoring_enabled` (Boolean) Whether the ServiceNow monitoring integration is enabled
- `servicenow_new_incident_action` (String) The Service Now action to take when a MTN Cloud incident is created (create, none)
- `servicenow_severity_critical_impact` (String) The ServiceNow impact level to map to the MTN Cloud critical severity (high, medium, low)
- `servicenow_severity_info_impact` (String) The ServiceNow impact level to map to the MTN Cloud info severity (high, medium, low)
- `servicenow_severity_warning_impact` (String) The ServiceNow impact level to map to the MTN Cloud warning severity (high, medium, low)

### Read-Only

- `id` (String) The ID of the monitoring setting
