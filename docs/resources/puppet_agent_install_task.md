# mtncloud_puppet_agent_install_task

A Puppet Agent Install task (console: Library > Automation > Tasks). Installs the Puppet agent on the instance the task runs against.

## Example Usage

```terraform
resource "mtncloud_puppet_agent_install_task" "agent" {
  name           = "puppet-agent"
  puppet_master  = "puppet-prod"
  puppet_version = "7"
  environment    = "production"
}
```

## Schema

### Required

- `name` (String) Task name.
- `puppet_master` (String) The Puppet master integration, by name.
- `puppet_version` (String) Agent version, as the console lists it, for example `7`.

### Optional

- `allow_custom_config` (Boolean) Let whoever runs the task pass custom configuration. Defaults to false.
- `code` (String) Task code, a short unique reference.
- `environment` (String) Puppet environment, for example `production`.
- `labels` (Set of String) Labels.
- `node_name` (String) Puppet node name. The platform's default is the instance's host name.
- `retry_count` (Number) How many times to retry when `retryable` is true. Defaults to 5.
- `retry_delay_seconds` (Number) Seconds between retries. Defaults to 10.
- `retryable` (Boolean) Retry the task when it fails. Defaults to false.
- `visibility` (String) `private` (your tenant only, the default) or `public`.

### Read-Only

- `id` (String) Task ID.
