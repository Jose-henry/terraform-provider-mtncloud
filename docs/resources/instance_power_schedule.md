# mtncloud_instance_power_schedule

Puts an instance on a power schedule (`mtncloud_power_schedule`): MTN Cloud then stops and starts it at the schedule's times. An instance is on one schedule at most; this replaces any it was on. Destroying this takes the instance off the schedule and leaves it in its current power state. Don't also set `power_state` on the instance's `mtncloud_instance`, or the two undo each other.

## Example Usage

```terraform
data "mtncloud_instance" "dev" {
  name = "dev-1"
}

resource "mtncloud_power_schedule" "office_hours" {
  name      = "office-hours"
  time_zone = "Africa/Lagos"
  saturday  = { on = "00:00", off = "00:00" }
  sunday    = { on = "00:00", off = "00:00" }
}

resource "mtncloud_instance_power_schedule" "dev" {
  instance_id       = data.mtncloud_instance.dev.id
  power_schedule_id = mtncloud_power_schedule.office_hours.id
}
```

## Notes

- **One schedule per instance.** Creating this replaces any schedule the instance was on. Use one of these per
  instance, for example with `for_each` over a set of instance IDs.
- **Stopped instances stay stopped** when this is destroyed: it only takes the instance off the schedule.
- **Taken off out of band:** when the instance is taken off its schedule in the console, the next plan puts it
  back. When it was moved to another schedule, the plan moves it back to this one.
- **Works on any instance you can edit,** including the VMs of catalog orders (`instance_ids` on the order).
- **`power_state` on `mtncloud_instance`** also starts and stops the VM: don't use both on one instance.

## Schema

### Required

- `instance_id` (String) ID of the instance, for example `mtncloud_instance.web.id`. Changing it moves the attachment to another instance.
- `power_schedule_id` (String) ID of the schedule, for example `mtncloud_power_schedule.office_hours.id`. Changing it moves the instance in place.

### Read-Only

- `id` (String) The instance's ID.

## Import

Import is supported using the following syntax:

```shell
# By the instance's ID: it imports the schedule the instance is on.
terraform import mtncloud_instance_power_schedule.dev 4652
```
