# mtncloud_instance (Data Source)

Looks up one instance (virtual machine) by ID, or by name, including one made in the console. A name must match exactly one instance; add `project` when the same name is used in several projects.

## Example Usage

```terraform
# An instance made in the console, by name. Add project if the name is used in several projects.
data "mtncloud_instance" "db" {
  name    = "db-1"
  project = "web-prod"
}

# The same lookup by ID, for example to import it: terraform import mtncloud_instance.db <id>
data "mtncloud_instance" "by_id" {
  id = data.mtncloud_instance.db.id
}

output "db_address" {
  value = data.mtncloud_instance.db.private_ip
}
```

## Schema

### Optional

- `id` (Number) Instance ID. Give this or `name`.
- `name` (String) Instance name, matched exactly. Give this or `id`.
- `project` (String) Project name (for example `web-prod`), to tell apart instances with the same name. The full platform name, with the tenant suffix, also works. Always set to the instance's project, without the suffix.

### Read-Only

- `cloud` (String) Cloud the instance is in, for example `MTNNG_CLOUD_AZ_1`.
- `group` (String) Group the instance belongs to.
- `image` (String) Image name, for example `MTN Ubuntu Server 24.04.3LTS`.
- `labels` (List of String) Labels.
- `networks` (List of String) Network IDs of the instance's network cards, primary first, as `mtncloud_instance` takes them.
- `plan` (String) Plan (size) name, for example `G2S4`.
- `private_ip` (String) Private address, or empty.
- `public_ip` (String) Floating (public) address, or empty.
- `security_groups` (List of String) Names of the security groups applied to the instance, sorted, the project's default group included. Null, with a warning, when your role can't read them.
- `status` (String) Status, for example `running` or `stopped`.
- `volumes` (Attributes List) Disks, root first. (see [below for nested schema](#nestedatt--volumes))
