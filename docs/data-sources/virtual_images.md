# mtncloud_virtual_images (Data Source)

Provides an MTN Cloud virtual images data source: lists the VM images you can see.

## Example Usage

```terraform
data "mtncloud_virtual_images" "example_virtual_images" {
  sort_ascending = true
  source         = "Synced"
  filter {
    name   = "name"
    values = ["Test*"]
  }

  filter {
    name   = "type"
    values = ["vmdk", "iso"]
  }
}
```
