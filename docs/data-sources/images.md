# mtncloud_images (Data Source)

Lists the operating system images you can create instances from, for example `MTN-U24.04LTS` (Ubuntu 24.04). Applications such as Kubernetes, databases and VPN are ordered from the catalog instead: see `mtncloud_catalog_items`.

## Example Usage

```terraform
# Operating system images. Applications (Kubernetes, databases, VPN...) are in the catalog:
# see mtncloud_catalog_items.
data "mtncloud_images" "all" {}

data "mtncloud_images" "ubuntu" {
  name_regex = "Ubuntu"
}

output "images" {
  value = { for i in data.mtncloud_images.all.images : i.code => i.name }
}
```
