# mtncloud_catalog_items (Data Source)

Lists the services you can order from the MTN Cloud catalog: projects, Kubernetes, managed databases, VPN, firewall, MTN Object Storage (MOS) and more. Pick an item by `name`.

## Example Usage

```terraform
# Everything you can order from the catalog.
data "mtncloud_catalog_items" "all" {}

# Only workflow items whose name mentions storage.
data "mtncloud_catalog_items" "storage" {
  type       = "workflow"
  name_regex = "(?i)storage"
}

output "catalog" {
  value = data.mtncloud_catalog_items.all.items[*].name
}
```
