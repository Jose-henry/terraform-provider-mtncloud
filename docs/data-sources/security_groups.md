# mtncloud_security_groups (Data Source)

Lists the security groups in a project, including the `default` group MTN Cloud creates with every project. Several projects can each have a group with the same name, which is why `project` is required.

## Example Usage

```terraform
# Security groups in a project, including the "default" group every project gets.
data "mtncloud_security_groups" "web" {
  project = "web-prod"
}

data "mtncloud_security_groups" "default" {
  project    = "web-prod"
  name_regex = "^default$"
}

output "default_security_group_id" {
  value = data.mtncloud_security_groups.default.security_groups[0].id
}
```
