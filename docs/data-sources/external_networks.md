# mtncloud_external_networks (Data Source)

Lists the external networks an MTN Router can connect to, for example `public-network-01`. A router on an external network gives the instances behind it a route to the internet.

## Example Usage

```terraform
# Networks an MTN Router can use to reach the internet.
data "mtncloud_external_networks" "public" {
  name_regex = "^public-"
}

output "external_networks" {
  value = data.mtncloud_external_networks.public.external_networks[*].name
}
```
