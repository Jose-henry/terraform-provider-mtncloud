## API shapes confirmed or corrected

Recorded in [api-research.md](api-research.md):
- Cypher: the stored key keeps the size segment (`password/20/<name>`); `ttl "8h"` reads back as a
  lease of 28800000 ms; no ttl reads 0.
- Security groups: the cloud sync re-creates rules with new IDs and names set to the port,
  restores rules deleted before the first sync, and sets a blank description to the group's name.
- Instances: `environmentPrefix` is null for API-made instances; NIC IDs read as null; a resize
  sent with the existing NICs adds a duplicate card.
- NFS/SMB: every order needs `updateType` with the quoted value (`'Append'`); the field's own
  default is refused.
- Customer role: 403 on `POST /api/certificates`, `/api/networks/floating-ips`, the library
  (option lists, option types, most tasks), NFS orders, and `/api/zones/{id}/resource-pools`
  (read and delete).
- API tokens for `morpheus-terraform` last 1440 s (24 min), and regenerating replaces the
  previous one. A long apply (a cluster) can outlive its token.
